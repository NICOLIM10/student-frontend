01 / about

Curious about how things actually work.

I’m Francisco Nicolai Lim, an Information Technology student who builds websites and web apps, from the page a user sees to the database behind it.

I write the front end in HTML, CSS, and JavaScript, handle server logic with PHP and Java, exchange data as JSON through REST APIs, and store it in MongoDB. I run and test locally with XAMPP, and deploy my APIs on Vercel.

Outside of class, I build small complete projects, like a nail business website, a game design project, and a student database app, to understand how every layer fits together.
